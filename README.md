# KFLU Builder Union (한국노총 경기남부본부)

한국노총 전국공공산업노동조합 건설산업분과 경기남부본부 공식 웹사이트입니다.

## 주요 기능
- **메인 페이지:** 본부 소개, 인사말, 활동 현황(갤러리), 상담 신청.
- **자유게시판:** 모든 사용자 읽기 가능, 로그인 후 글쓰기/수정/삭제 가능.
- **관리자 페이지:** 회원 관리 및 공지사항 작성.
- **RSS/Sitemap:** SEO 및 네이버 검색 연동을 위한 자동 생성 기능.

## 기술 스택
- Frontend: Vanilla JS, Tailwind CSS, Web Components
- Backend: Firebase (Auth, Firestore, Hosting)
- Automation: GitHub Actions (RSS 자동 업데이트)
